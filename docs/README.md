## Subtrees

- `ai/`
  AI- and agent-oriented implementation guidance for the frontend, including stack notes, UI guidance, reusable patterns, and example snippets.
- `terminology/`
  Controlled terminology for frontend user-visible text, including the machine-readable source file and the human-readable policy.

## Usage

- Put stable architectural knowledge in `architecture.md`.
- Put local setup, workflows, and troubleshooting in `development.md`.
- Put AI- and agent-oriented repository context in `ai-context.md`.
- Put task-specific frontend implementation guidance in `ai/`.
- Put terminology rules and the terminology source of truth in `terminology/`.
