# Pattern: page layout

## Use this pattern for

- index pages
- admin screens
- settings pages
- overview pages with actions and content

## Standard structure

1. page title
2. short optional subtitle
3. primary actions on the right
4. optional filter or summary row
5. main content card or section
6. empty, loading, and error states inside the content region

## Rules

- primary actions stay near the title area
- filters should not be mixed into unrelated action groups
- destructive actions should not be primary by default
- avoid deep nesting of cards inside cards unless already common in the app
